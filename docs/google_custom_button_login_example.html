Google 第三方登入 WS 範例

這個範例使用 Google Identity Services popup code flow。Google 會把 authorization code 回給本頁， 本頁再送 google_login 到遊戲 WebSocket。請用 http/https 開啟，不要使用 file://， 並在 Google Cloud Console 的 Authorized JavaScript origins 加入目前 origin。popup code flow 通常使用 origin， 例如 http://127.0.0.1:8010，不是完整 HTML 檔案路徑。
